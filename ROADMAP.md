# Quietora Focus — Product Roadmap

## Status: v2.0 Advanced Edition (Released)

### Completed in v2.0
- [x] Multi-mode focus engine (Deep Focus, Pomodoro with cycle progression, Study Mode, Work Mode, Custom).
- [x] Personal PC Memory with permission-based folder indexing and SQLite FTS5 search.
- [x] Integrated Task & Goal manager with priorities, subject tags, and deadline tracking.
- [x] Activity Timeline and distraction intervention logging.
- [x] Productivity Analytics with 7-day activity distribution chart, top distractions, and rule-based tips.
- [x] Modern Windows 11 Fluent UI with Dark and Light mode themes.
- [x] Win32 System Tray integration with instant restore and background awareness.
- [x] Structured diagnostic file logging with strict privacy scrubbing.
- [x] Backward-compatible versioned database migrations preserving all earlier records.
- [x] Open data export (CSV sessions, CSV tasks, CSV distractions, TXT summary report) and nuclear wipe.
- [x] 100% automated test coverage across domain logic, migrations, FTS5 search, and exports.

## Future Horizon: v2.1 & v2.2

### v2.1 — Companion Browser Integration (Opt-in)
- Manifest V3 browser extension for Google Chrome and Microsoft Edge.
- Authenticated, local-only communication protocol with the Quietora Focus desktop app via native messaging or local HTTP loopback.
- Voluntary website domain blocking synchronized with active focus sessions.
- Clear, prominent emergency bypass toggle inside the extension popup.
- Zero tracking of browser history, URLs, or page contents.

### v2.2 — On-Device Intelligence & Expanded Indexing
- Optional local semantic search using on-device embedding models (e.g. lightweight ONNX Runtime execution).
- Enhanced file parsing for PDF text streams and Microsoft Word (.docx) document bodies.
- Smart schedule recommendations based on historical peak focus hours.
- Automated weekly productivity email digests (via local SMTP or export).

---

## Long-Term Vision: v3.0

- Voluntary institutional pilot framework for universities and coaching institutes:
  - Aggregate, anonymized focus engagement metrics only with explicit student consent.
  - No private activity logs, browsing history, or surveillance features.
  - Zero cloud reliance for individual users.
