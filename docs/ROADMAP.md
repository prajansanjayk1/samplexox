# Product Roadmap (v3.1 — v4.0)

## Quietora Focus — Future Development Plan
**Parent Brand:** QuietoraLabs

---

## 1. Version Milestones

### v3.1 — Deep Semantic Memory & Institutional Readiness (Q1 2027)
- **Local ONNX Embeddings Runtime**: Optional small ONNX model (`all-MiniLM-L6-v2`, ~80MB) running via DirectML/CPU for dense semantic vector embeddings alongside SQLite FTS5.
- **Institutional Multi-Seat Policy Templates**: Standardized focus configurations for university computer labs, software engineering bootcamps, and high-focus study halls.
- **Enhanced Document Extractors**: Native parsing for Word (`.docx`) and PowerPoint (`.pptx`) outlines without Microsoft Office installed.

### v3.2 — Cross-Device Peer Synchronization (Q2 2027)
- **Peer-to-Peer Local Sync**: Local Wi-Fi sync using encrypted peer discovery (zero cloud servers) to synchronize session streaks between a student's Windows desktop and laptop.
- **Audio Soundscapes**: Built-in binaural beats, pink noise, and focus ambient generators with zero internet connection required.

### v4.0 — Autonomous Focus Operating System (Q3 2027)
- **Predictive Fatigue Detection**: Machine learning model analyzing typing rhythm and application switching cadence to suggest rest breaks before burnout.
- **Multi-Monitor Spatial Window Grouping**: Automatic organization of workspaces across multiple physical displays upon session launch.
- **Plugin Architecture**: Safe sandbox for user-contributed automations and custom exporters.
